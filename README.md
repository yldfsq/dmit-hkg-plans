## 先把「三网直连」这个词拆开

中国大陆三张网，各自有一条公认的好线路：

- 电信：CN2 GIA（AS4809），下一代承载网，绕开普通 163 骨干的拥堵节点
- 联通：AS9929 精品网，或 AS4837 + AS10099 组合
- 移动：CMI，中国移动国际出口

所谓「三网直连」，理想状态是这三家去程回程都走优化线路。现实里更常见的情况是：只优化电信，联通移动随便绕；或者只优化回程（从机房回你），去程（你访问机房）还是走公共线路。**回程好、去程差的产品，你上传文件和访问控制面板时会明显感觉卡。**

买之前值得花五分钟做一件事：拿商家给的测试 IP 分别用电信、联通、移动网络 ping 一遍，再跑一次路由追踪。香港节点到国内主要城市的正常水平在 50ms 以内，超过 80ms 基本可以判断没有认真优化。

## 几个高频问题

**「三网直连」是营销词吗？**

不是，但它常被滥用。判断标准很具体：看商家有没有公布三家的去程和回程走什么线路。只写「三网优化」而不写具体 AS 号的，大概率只优化了回程。

**Pro 和 EB 差多少？**

线路差一档，价格差一档，库存稳定性差得更多。Pro 是电信双向 CN2 GIA，EB 是电信去程 CTG GIA、回程走 163，移动双向 CMI 表现好。电信用户选 Pro，移动用户选 EB 是稳妥的划分。

**香港机房需要备案吗？**

香港机房不属于境内，不需要 ICP 备案，这也是很多人选香港而不是国内机房的原因之一。

**流量超了会怎样？**

Pro 和 EB 系列流量用尽后按官方规则处理；T1 系列是限速不限量，降到 50Mbps 到 1Gbps 继续用，不会直接断流。如果你跑的是持续性的流量任务而不是网站访问，T1 的这一点比它的价格更有吸引力。

**延迟大概多少？**

Premium 系列到国内三网普遍在 40ms 上下，Eyeball 在 30–70ms 区间波动，Tier 1 没有优化保证。这些数字受运营商、地区和时段影响，用测试 IP 自己测一遍最靠谱。
